# Muadil İlaç — Privacy Policy GitHub Pages

Bu klasör, Google Play Console’da gizlilik politikası URL’si olarak kullanılabilecek statik sayfayı içerir.

## GitHub Pages’a yayınlama

1. GitHub’da herkese açık yeni bir repository oluşturun. Örneğin: `muadil-ilac-privacy`.
2. Bu klasördeki `index.html` dosyasını repository köküne yükleyin.
3. Repository içinde **Settings > Pages** bölümünü açın.
4. **Source** olarak `Deploy from a branch`, branch olarak `main`, klasör olarak `/ (root)` seçin.
5. **Save** düğmesine basın.
6. GitHub’ın verdiği `https://KULLANICI_ADINIZ.github.io/muadil-ilac-privacy/` adresini gizlilik politikası URL’si olarak Play Console’a yazın.
7. URL’yi gizli sekmede açıp sayfanın herkes tarafından görülebildiğini kontrol edin.

## Yayınlamadan önce değiştirin

`index.html` içindeki “İletişim” bölümüne gerçek destek e-posta adresinizi ekleyin. Sayfadaki tarih, marka, AdMob ve Billing açıklamalarını gerçek yapılandırmanızla karşılaştırın.

## Güvenlik uyarısı

Bu repository’ye hiçbir zaman `.jks`, `.keystore`, `KEYSTORE-CREDENTIALS.txt`, `.aab`, Play Console parolası, AdMob gizli bilgisi veya kişisel ödeme bilgisi yüklemeyin. Upload keystore yalnızca özel ve güvenli yedeklerde saklanmalıdır.
